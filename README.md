# game-alpha

微信小游戏：俯视角生存肉鸽（Survivor-like）。原生 Canvas 2D + 微信 wx API，无游戏引擎。

在一个 2000x2000 的地图里无限刷怪，走位躲避、自动反击，捡经验升级、开宝箱拿增益，看你能活多久。

> 开发计划见 [TODO.md](TODO.md)，美术出图清单见 [ART.md](ART.md)。

## 玩法

- **首页**：启动后进的是首页（标题 + 开始游戏 + 设置 / 怪物图鉴 / 游戏记录），死亡结算页可选「再来一局」或「返回首页」
- **设置**：伤害飘字、受击振动可开关并本地保存；音效、背景音乐为待接入的占位开关
- **怪物图鉴**：游戏中遭遇过的怪（含宝箱怪与 Boss）自动解锁；点条目进详情页，看**学名 + 分类阶元 + 游戏机制 + 一句真实冷知识 + 数值**，可「上一只 / 下一只」翻页
- **游戏记录**：本地保存最长生存、最高等级、最多击杀、累计开箱，并保留最近 5 局战绩
- **移动**：按住屏幕任意位置拖动，全屏虚拟摇杆
- **攻击**：自动索敌最近的怪并射击，无怪时朝移动方向开火；角色是俯视持枪，会转身对准目标，子弹从枪口打出并带火光
- **升级**：经验满后暂停，三选一强化卡
- **伤害飘字**：命中时怪物头顶上浮出伤害数字，白色为普通伤害，黄色放大为暴击
- **宝箱怪**：金色匣子（全身闪烁提示），击杀掉宝箱，拾取随机获得：子弹数+1 / 穿透+1 / 护盾+1 / 跟班+1
- **跟班**：环绕角色飞行，固定 1.5 次/秒自动射击，伤害为角色攻击力的一半，继承穿透与暴击
- **减速**：目前唯一的非伤害型负面状态。踩进膜王的黏液洼会掉移速，左上角属性面板的移速数字实时跟着掉、离开后还要拖 0.7 秒才回满；黏液**不结算伤害**，所以不占用受击无敌帧（踩一下黏液不会让下一发子弹白嫖）

## 怪物

主题：**病毒 · 微生物**。玩家是穿蓝雨衣的防疫人员，每只怪的行为都对应真实的感染 / 耐药机制。

命名分两层：**显示名是好喊的外号**（两个字、能跟朋友说"一波刺头过来了"），真实学名放在图鉴详情页第二行当知识回报。

| 外号 | 学名 / 分类 | 识别色 | 特点 | 解锁时间 |
|------|------------|--------|------|----------|
| 刺头 | Coronaviridae · 有包膜 RNA | 青色 | 基础近战追击，最常见的杂兵 | 开局 |
| 窜子 | Influenzavirus A · 甲型流感 | 橙色 | 血薄速度快，容易贴脸 | 25 秒 |
| 铁坨 | Staphylococcus aureus · 金葡菌 | 紫色 | 血厚伤害高、移动缓慢 | 45 秒 |
| 喷子 | Filoviridae · 丝状病毒 | 红色 | 250 距离内站桩喷射，子弹无射程上限 | 60 秒，刷新权重较低 |
| 金匣 | Plasmid · 质粒 | 金色 | 击杀不掉经验，掉宝箱（水平基因转移） | 15 秒后每 25 秒一只 |
| 毒王 | Human betaherpesvirus 5 · 人巨细胞病毒 | 暗红 | Boss：3000 血，接触伤害 15，掉 300 经验 | 120 秒 |
| 海火 | Noctiluca scintillans · 夜光藻 | 荧光青 | Boss：4600 血，定身自转扫 3~5 道激光，间或铺赤潮封落脚处 | 240 秒 |
| 膜王 | Pseudomonas aeruginosa · 铜绿假单胞菌（生物膜态） | 象牙白 | Boss：28000 血，外层黏膜按厚度折减近七成伤害，吐出的菌群爬回去补膜；黏液洼只减速不掉血 | 360 秒 |

90 秒后所有怪物血量 ×1.5，刷怪间隔随时间从 2.5 秒压缩到 0.45 秒。

首页图鉴的文案全部来自 `js/npc/monster/config.js`：`name`（外号）/ `latin`（学名）/ `group`（分类阶元）/ `intro`（机制）/ `fact`（冷知识），展示顺序与「出现条件」文案由 `CODEX_ORDER` 控制。识别色 `color` 的优先级高于真实配色（玩家靠颜色分辨怪类型，而病原体本身没有颜色），不符时在图鉴里说明。

> 当前 `images/entity/` 里生效的是**第一批 Q 版贴图**（正面朝上、不随朝向旋转，`SPRITE_ROTATES = false`），造型还没跟上微生物主题。上一版「头朝右 + 会旋转」的昆虫造型原图存在 `vibe_images/insect_v1/`，切回方式见 [ART.md](ART.md) 第九节。

**Boss**：出场时间由 `config.js` 的 `BOSS_SCHEDULE` 表驱动（毒王 120 秒、海火 240 秒、膜王 360 秒），上一只被击杀 15 秒后才刷下一只，同屏始终只有一只 Boss，顶部血条 + 弹窗提示。Boss 存活期间**普通刷怪照常走，只是间隔乘 `BOSS_SPAWN_INTERVAL_MULT`（默认 2 = 密度减半）**，宝箱怪完全不受影响；想回到「Boss 存活就完全不刷小怪」把该常量改到极大即可，别去动 `spawner.js`。**三只的技能与冲锋时间轴一律 dt 累加、不读 `Date.now()`**，所以升级三选一面板开着的时候整场施法真的冻在原处（毒王早期用时间戳，冲锋会在面板里被白白烧掉，2026-09-19 已改齐）。Boss 走 `BOSS_SCHEDULE`，不吃「90 秒后血量 ×1.5」那条普通怪成长。

> 2026-09-19 三只血量按用户体感一律 ×10 之后，站桩台（玩家钉住、神血、固定 build）实测的中 build 时长：**毒王 ≈101 秒、海火 ≈87 秒、膜王 286 秒（把菌群全拦下）/ ≈1320 秒（一只都不拦）**。膜王那一场不是线性的——它的膜是速率平衡，血 ×10 把「不回头清菌群」这一支放大得最狠，详见 `MONSTER_TYPES.boss3.hp` 上方注释。
>
> 击杀 Boss 掉的那一颗经验宝石值 300~600，够连跳好几级。`Player.addXp` 一次只结一级，剩下的溢出经验由升级面板关闭时再结算一次，所以**一颗宝石 = 连着弹好几张三选一**，经验条不会停在「590/170」那种填不满的样子。

- **毒王**：每 4 秒循环 —— 冲锋（700ms 高速冲刺，冲锋中外面一圈警示红圈）→ 环形弹幕（12 发）→ 召唤 3 只普通小怪。
- **海火**：施法期定身不动，两个技能交替 —— **海火扫射**（身体绕轴自转，把 3~5 道光束"扫"出去，血量越低点亮的眼越多；三段 正→反→正，换向前有人字箭头预告）→ **赤潮**（3 片围着它自己 + 1 片压在玩家脚下的发光水体，先虚线圈预警再落地）。光束角度只来自身体自转，永不朝玩家修正；技能时间轴用 dt 累加，所以升级三选一暂停时整个施法会冻在原处。
- **膜王**：三条互相独立的冷却（齐射 4.2 秒 / 吐菌群 7.6 秒 / 铺黏液 9 秒）外加一层**和冷却正交的膜**——膜不是第二条血，是"伤害折损"：吃到的每发子弹先按 `filmBurn` 啃膜，再按剩余膜厚线性打折（满膜 68% 减伤）。**侵蚀按原始伤害算，所以膜永远破得开（不会软锁）**，破满膜固定要 2000 点原始伤害，与 build 无关；破膜后 3.6 秒 2 倍伤害窗口是**固定时长**而不是 DPS 奖励，弱 build 也一定拿得到。膜自己的回分泌几乎可以忽略、且只能长回 60%，**唯一能把膜补回满值的途径是底部孔口吐出的三只菌群爬回来嵌进去**（血量是杂兵的 3 倍，所以不会被溅射白嫖，"拦不拦"才构成决策）——被吃回去的菌群不掉经验也不涨击杀数。本体只在 ±24° 内**倾身**瞄准（贴图有明确上下，不整圈转），三根烟囱撑出约 303° 可打范围，**正下方约 57° 是齐射死角，但那个方向的齐射会自动改喷菌群，所以死角不是安全区，恰恰是最该回头清场的位置**。黏液洼只减速 45%、完全不结算伤害，因此不占用全局 500ms 无敌帧。

## 角色升级项

生命上限 / 移动速度 / 攻击力 / 防御力 / 攻击速度（次/秒，加法叠加）/ 攻击距离（=索敌距离）/ 暴击率 / 幸运值（每点 +2% 经验获取）

此外**每升 1 级还会自动成长**（在三选一之外叠加）：攻击力 +1、暴击率 +2%、攻击距离 +5、移速 +5。数值见 `js/consts.js` 的 `LEVEL_UP_BONUS`（key 必须与 Player 属性名一致）。

## 调参指南

可调数值集中在下列文件，均有中文注释：

- `js/consts.js`：游戏标题（`GAME_TITLE`，当前暂定 game-alpha）、角色基础属性、子弹参数、伤害飘字（`DAMAGE_TEXT_*`）、经验曲线（`xpForLevel`）、升级项数值（`UPGRADES`）
- `js/npc/monster/config.js`：怪物血量/速度/伤害、刷怪节奏（含 Boss 存活期间的密度倍率 `BOSS_SPAWN_INTERVAL_MULT`）、解锁时间、远程怪子弹、刷新权重、Boss 技能数值与出场表（`BOSS_SCHEDULE` / `BOSS_FIRST_SPAWN_TIME` / `BOSS_SECOND_SPAWN_TIME` / `BOSS_THIRD_SPAWN_TIME` / `BOSS_RESPAWN_GAP`）、图鉴文案（`name` / `latin` / `group` / `intro` / `fact` / `CODEX_ORDER`）、贴图路径（`sprite`）。
  **带 ★ 的字段是公平性硬上限，不是手感参数**，改前必须先算它注释里那条不等式（举几个：海火 `laserWidth`×`spinSweep` 的缝宽、膜王 `colonySpeed ≤ 无升级移速 × slowMult`、`filmReduce ≤ 0.95`、`filmRegen < 最弱 build 的侵蚀速度`）。
  **Boss 的 `hp` 先按"目标秒数 × 实测有效 DPS"反解**，不要凭感觉填：在 `tools/preview.html` 里把玩家钉住、`__pump` 打到死量出时长，三个 build 档的数连同算法一起抄进 `MONSTER_TYPES.bossN.hp` 的注释。**例外是用户会按体感覆盖反解结果**（2026-09-19 三只一律 ×10：300→3000、460→4600、2800→28000），覆盖不是算错了，所以注释里要同时留「原反解」和「覆盖后重测的秒数」，别只留一个。改 `hp` 对毒王/海火是按时长线性平移；**膜王不是线性的**，它的膜是速率平衡，血翻倍会把「不回头清菌群」那一支放大得远比「全拦」那一支狠。
  膜王最容易踩的坑是**钉膜**：`colonyCount × filmPerEmbed ÷ colonyCd ≥ 玩家原始DPS × filmBurn` 一旦成立，膜就永远满值、这场直接卡死。这条分水岭写在 `filmPerEmbed` 的注释里（当前取值下约等于"原始 DPS 47 以下的玩家如果一只菌群都不拦"）；血 ×10 之后它咬得更狠——中 build 一只不拦实测 ≈1320 秒，而同一台子全拦下只要 286 秒。
- `tools/sprite_keying.ps1`：把 AI 出的纯色底精灵图转成游戏可用的 @2x 透明 PNG（抠底 → 去水印 → 只留主体连通块 → 裁边 → 等比缩放 → 居中）。改完 `js/consts.js` / `config.js` 里的半径后跑一次 `-Sheet` 即可重出 `images/entity/` 和 `vibe_images/contact_sheet.png`
- `js/ui/home.js`：首页四个页面的按钮尺寸与排版（改一处 `draw` 即可，命中判定与绘制共用同一份区域）
- `js/storage.js`：本地存储键 `ga_settings_v1`（设置）与 `ga_records_v1`（战绩/图鉴），默认值见 `DEFAULT_SETTINGS`；换存档格式时改键名后缀即可

注意：升级项的 `key` 必须与 Player 的属性名一致（如 `attackRange`、`companions`），否则升级会静默无效。

### 本地验收工具（不需要开发者工具）

- `node tools/preview.mjs <端口>` 起静态服务后浏览器开 `tools/preview.html`：一张 390×844 的真机竖屏画布 + 一排「跳页」按钮（首页/对局/三只 Boss/升级/结算/图鉴详情）。窗口上有三个探针：`__freeze()` 停掉自动帧链（之后必须手动 `__pump(ms)` 走单帧，否则按钮里的 `setTimeout` 会和 `start()` 的 `reset()` 抢时序）、`__pump(ms)` 泵一帧并把 `Date.now` 往前推、`__shot(name)` 把当前画布存进 `.preview/shots/`。把 `main.render` 临时替换成空函数就能让逻辑以约 100 倍速跑，Boss 血量的 DPS 反解就是这么量的
- `node tools/headless_check.mjs <秒数>` 完全不进浏览器：用一套 wx stub 把整局跑到底，只报 `non-finite ctx args` / `errors` / 贴图加载 / Boss 状态与膜层统计。**默认 60 秒跑不到任何 Boss 分支，看 Boss 必须给到 480**。它同时是 Canvas 参数陷阱的守门员——但 `arc` 的负半径抛的是 `IndexSizeError` 不是 NaN，这类只有真机能测出来，画之前自己 `Math.max(0.5, …)`
